# 🚀 TYPE BLASTER – 2D Space Shooter Typing Game & Speed Test

**TYPE BLASTER** is a modern, responsive, and gamified typing speed trainer and arcade space shooter. Defend your sector from descending alien armadas, meteor clusters, and dreadnoughts by typing target words accurately on your keyboard or mobile touchscreen.

---

## 🌟 Features

- **🎮 Dual-Genre Arcade Gameplay**: Classic vertical space shooter integrated with precision touch typing mechanics.
- **⚡ Real-Time Typing Telemetry**: Live WPM (Words Per Minute), Accuracy percentage, Net vs. Gross WPM, and Combo streaks.
- **📱 Full Mobile Support**:
  - Transparent low-latency virtual keyboard bridge for iOS / Android (Gboard, Samsung, Apple).
  - Built-in Retro Cyber On-Screen QWERTY touch keyboard.
  - Progressive Web App (PWA) with offline Service Worker and Add-to-Home-Screen support.
- **🔊 Procedural Audio Synthesis**: 100% offline Web Audio API sound effects (lasers, explosions, shield alarms) and a dynamic 16-step retro synthwave soundtrack.
- **🎯 3 Dedicated Game Modes**:
  1. **Arcade Mode**: 20+ progressive waves with escalating speed and alien classes.
  2. **Typing Practice**: Drills for Home Row, Top Row, Bottom Row, Developer Code Keywords, and Extreme Vocabulary.
  3. **Speed Test Benchmark**: 1, 2, or 3-minute standardized test with a final mission debrief certificate.
- **📊 Diagnostic Reporting**: Identifies and logs your personal weak key combinations to pinpoint areas for speed improvement.
